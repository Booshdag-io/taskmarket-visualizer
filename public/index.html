Server-Side Refresh & Caching

Browser requests to api.taskmarket.dev are blocked by CORS from third-party origins. A scheduled GitHub Actions workflow runs node scripts/fetch-data.mjs every hour, writes public/data/snapshot.json, and publishes static assets to GitHub Pages with HTTP cache headers (max-age=600).
